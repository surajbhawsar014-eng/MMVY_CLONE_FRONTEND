# MMVY Portal Clone (React + Vite)

A **practice / UI-clone project** of the Mukhyamantri Medhavi Vidyarthi Yojana (MMVY) portal, built to practise React, responsive CSS and component design.

> ⚠️ This is **not** the official portal and is **not affiliated with** the Government of Madhya Pradesh or NIC. It collects no data and has no login. For real applications use the official website.

## Features
- Fully responsive layout (desktop / tablet / mobile hamburger menu)
- Dropdown navigation, live clock, A- / A / A+ font-size controls
- Pop-up notice modal (closes on X or outside click)
- Data-driven components (`src/data.js`)

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Tech
React 18 · Vite · Font Awesome · Netlify
